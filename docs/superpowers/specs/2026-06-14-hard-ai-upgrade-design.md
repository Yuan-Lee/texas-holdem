# Hard AI 升级设计

## 概述

对现有 Hard 难度 AI 进行全面升级，使用三层混合决策引擎，实现自适应打牌风格。

## 架构

```
三层决策引擎，优先级依次执行：

玩家行动 → 第1层：启发式快判 → 能决定？→ 返回
                             ↓ 不能
                  第2层：对手范围推演 → 能决定？→ 返回
                                        ↓ 不能
                            第3层：MC强化模拟 → 返回
```

**决策时间预算**：2 秒
- 第1层：< 10ms
- 第2层：< 500ms
- 第3层：剩余用于 MC（约 1.5s，~3000 次）

## 对手画像系统

全局累计（游戏过程中持续累积，每手牌后更新）。

| 指标 | 含义 |
|------|------|
| VPIP | 主动入池率 |
| PFR | 翻牌前加注率 |
| AF | 侵略系数 |
| Fold to CBet | 面对持续下注的弃牌率 |
| WTSD | 摊牌率 |

**文件**：`src/ai/opponentModel.ts`
- `ProfileTracker` 类，全局跟踪每个 `playerId` 的统计数据
- `recordAction(state)` — 记录每个行动
- `getProfile(playerId)` — 获取对手画像
- 数据在 `nextHand()` 中由 `useGameStore` 触发更新

## 下注额策略

| 意图 | 翻牌后下注额 |
|------|------------|
| 小注 | 底池 1/3 |
| 中注 | 底池 1/2 |
| 大注 | 底池 3/4 |
| 超池 | 底池 100-120% |

| 翻牌前场景 | 加注额 |
|-----------|--------|
| 无人加注开局 | 2.5-3 BB |
| 3-bet | 3-4 倍对方加注 |
| 4-bet | ~22-25 BB |

选择因素：牌力、对手弱点、牌面结构、筹码深度。

**文件**：`src/ai/betSizer.ts`
- `calculateBetSize(params): number`

## 决策引擎流程

### 第1层：启发式快判
- 坚果/几乎坚果 → 加注/All-In
- 完全空气 + 对手示弱 → 诈唬
- 对手坚果范围 + 自己弱 → 弃牌
- 可 Check → Check
- 短筹码 (<10BB) → 推/弃

### 第2层：对手范围推演
- 读取对手画像
- 根据行动缩小对手范围
- 计算胜率 vs 范围
- 底池赔率判断 EV
- EV 差 > 20% → 直接决策
- EV 接近 → 降级到第3层

### 第3层：MC强化模拟
- 对手范围加权 MC
- 对每种可选动作分别模拟 EV
- 选择 EV 最高动作
- 10% 概率策略扰动
